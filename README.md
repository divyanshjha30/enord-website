## ✨ Features

- **Product Showcase** — Detailed pages highlighting drone products and capabilities
- **Responsive Design** — Fully optimized for desktop, tablet, and mobile
- **Modern UI** — Clean layout with styled-components and smooth interactions
- **Contact Page** — Easy way for potential clients to reach out
- **Fast Navigation** — Client-side routing with React Router

## 🚀 Getting Started

```bash
git clone https://github.com/divyanshjha30/enord-website.git
cd enord-website
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```
